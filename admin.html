Publish to Learnings

How publishing works

Articles you write here are saved in this browser only. Visitors and Google see what is in data/learnings.json in the GitHub repository. To publish:

  1. Write and save the article in New Article.
  2. Click Download articles JSON below.
  3. Paste the entries into the articles array of data/learnings.json and commit.
  4. For PDFs and PPTs, upload the file to the files/ folder and add an entry under documents with title, type, category, description, date and file path.

Document entry template

{
  "id": "los-selection-checklist-2026",
  "title": "LOS Selection Checklist for NBFCs",
  "type": "pdf",
  "category": "los",
  "description": "A one-page checklist for evaluating loan origination systems.",
  "date": "2026-10-06",
  "file": "files/los-selection-checklist.pdf",
  "pages": 1
}
